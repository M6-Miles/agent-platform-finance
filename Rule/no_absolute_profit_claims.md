# Rule: 禁止违规投资建议用语

**ID**: rule-003  
**优先级**: HIGH  
**适用范围**: 所有面向用户的输出（分析报告、聊天回复、交易建议）

## 规则内容

禁止在任何输出中出现以下类型的确定性收益承诺用语。

## 关键词黑名单

```
绝对稳赚, 100%收益, 稳赚不赔, 一定涨停, 肯定上涨,
必涨, 稳赚, 包赚, 无风险套利, 保证盈利,
内幕消息, 坐庄, 庄家, 操盘
```

## 执行动作

`KeywordBlocker.validate_output()` 检测到违规词时：
1. 抛出 `GuardrailViolation`，阻断输出
2. 要求 Agent 重新生成（最多3次）
3. 超过重试次数则替换为标准免责声明

## 强制免责声明

所有分析输出结尾必须包含：
> ⚠️ 仅供研究参考，不构成投资建议。股市有风险，投资需谨慎。
