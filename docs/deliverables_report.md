## D. 单笔亏损风控

Risk Manager 已按原说明书语义修正：

```text
止损距离 = (参考价 - 止损价) / 参考价
预计账户损失 = 批准仓位比例 × 止损距离
预计账户损失必须 ≤ 账户权益的 2%
```

缺少有效参考价或止损价的买入建议不会自动批准。行业仓位 30%、组合回撤 15%、流动性、交易时段和人工审批规则继续保留。
